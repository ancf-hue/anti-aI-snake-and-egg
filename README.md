  # 🐍🥚 Анти ИИ: Змея и Яйцо (Snake and Egg)

> **Нежная тяга.** Бесплатная социальная офлайн-веб-игра, развивающая внимательность, контроль и цифровую гигиену.

## 📖 Описание
Это медитативная, но напряжённая 3D-мини-игра, в которой вам нужно помочь стеклянной красной змее аккуратно дотащить хрупкое яйцо до гнезда на вершине склона. 

Главная механика — **точный контроль силы**. Удерживайте уровень тяги в безопасной зоне (10–30%). Если потянуть слишком резко (выше 30%), яйцо треснет и разобьётся. Игра бросает вызов вашей способности сохранять спокойствие и точность в условиях ограниченного времени.

## ✨ Особенности
- 📱 **PWA-готовность и офлайн-работа**: игра запускается в любом браузере, не требует установки и не собирает данные.
- 🎮 **Уникальная механика**: плавная физика разгона и торможения, система трещин и визуальная обратная связь.
- 🎨 **Современная 3D-графика**: построена на `Three.js` с динамическим освещением, тенями, частицами и эффектом стекла (Glassmorphism UI).
- 🔊 **Иммерсивный звук**: процедурная генерация звуков через Web Audio API и озвучка событий через Web Speech API (Text-to-Speech).
- 🌍 **Двуязычность**: полная поддержка русского и английского языков (RU / EN).
- 🏆 **Интеграция с Доской почёта**: безопасная система сохранения достижений с криптографической подписью токена.

## 🎯 Как играть
1. Нажмите кнопку **«▶ На старт!»**.
2. Нажмите и удерживайте большую круглую кнопку **«ТЯНИ НЕЖНО»** (или клавишу `Пробел` на клавиатуре).
3. Следите за вертикальным индикатором **«ТЯГА»** справа:
   - 🔵 **Ниже 10%**: яйцо медленно сползает вниз.
   - 🟢 **10% – 30%**: идеальная зона, яйцо плавно поднимается вверх.
   - 🔴 **Выше 30%**: опасность! Яйцо получает трещину. 3 трещины = поражение.
4. У вас есть **3 минуты**, чтобы достичь 100% прогресса и доставить яйцо в гнездо.

## 🛠 Технологии
- **HTML5 / CSS3** (адаптивный дизайн, `env(safe-area-inset)` для мобильных, анимации)
- **Vanilla JavaScript** (без тяжёлых фреймворков, максимальная производительность)
- **Three.js (r128)** (3D-рендеринг, физика движения, система частиц)
- **Web Audio API** (синтез звуков без внешних файлов)
- **Web Speech API** (голосовые подсказки)

## 🚀 Как запустить
1. **Локально**: просто откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge).
2. **В интернете**: загрузите репозиторий на **GitHub Pages** или любой статический хостинг (Vercel, Netlify). Игра полностью готова к развёртыванию как Single Page Application (SPA).
